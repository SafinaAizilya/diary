# Мой дневник

Личный дневник с записями и фотографиями. Учебный проект по дисциплине «Web-программирование».

---

## О проекте

**Тема:** личный дневник, где можно сохранять свои мысли, события и фотографии.

**Объект коллекции:** одна запись дневника.

**Свойства объекта:** название, описание, дата, настроение, теги, изображение.

**Для кого:** для людей, которые хотят вести личный дневник с фотографиями в удобном веб-формате.

**Почему выбрана эта тема:**
- Это коллекция однотипных объектов, что соответствует требованию лабораторной работы.
- Проект легко развивать: в следующих лабораторных можно добавить поиск, редактирование записей, авторизацию и базу данных.
- Тема визуальная, позволяет наполнить страницу осмысленными данными.

## Форма поиска

Форма содержит три поля разных типов и кнопку:

| Поле | Тип | Назначение |
|---|---|---|
| Название | `<input type="text">` | Поиск по названию |
| Настроение | `<select>` | Выбор из списка |
| С даты | `<input type="date">` | Выбор даты |
| Кнопка | `<button type="submit">` | Отправка формы |

У каждого поля есть видимая подпись `<label>` с атрибутом `for`, `id`, совпадающий с `for`, и `name` для отправки данных на сервер в будущем.

Форма пока не выполняет поиск - это будет добавлено в следующих лабораторных работах.

### Раскладка: Grid и Flexbox

**CSS Grid — для сетки карточек.** Используется свойство `grid-template-columns: repeat(auto-fill, minmax(260px, 1fr))`. Это значит: сколько колонок влезет, столько и будет; каждая колонка минимум 260px, максимум — доля свободного места. Благодаря этому карточки перестраиваются автоматически под ширину экрана без медиазапросов.

**Почему Grid:** сетка карточек — двумерная раскладка (строки и столбцы). Grid задаёт её одним свойством.

**Flexbox — для одномерных раскладок:**
- `.header` — логотип и навигация в одну строку;
- `.nav` — ссылки в строку;
- `.search-form` — поля формы в строку;
- `.field` — label над полем (в столбик);
- `.footer` — две части подвала.

**Почему Flexbox:** шапка — одномерная раскладка. Нужно разнести элементы по краям и выровнять по центру. Flexbox решает это в двух строках.

### Доступность

- У всех полей формы — видимые `<label>` с `for`.
- У содержательных изображений — осмысленный `alt`.
- Outline не убран, а заменён на собственный: `outline: 2px solid #c48b9f; outline-offset: 2px;`. Это позволяет пользователю, который перемещается клавишей Tab, видеть, где он находится.
- Кнопки — `<button>`, а не `<div>` или `<span>`, чтобы работали с клавиатуры.
- Ссылки — `<a>` с реальными якорями (`#records`, `#search`, `#about`), а не `href="#"`.

### Адаптивность

Проверено на трёх ширинах.

| Ширина | Раскладка |
|---|---|
| 360px | Карточки в одну колонку, шапка и подвал в столбик |
| 768px | Карточки в две колонки |
| 1280px | Карточки в три-четыре колонки |

Медиазапрос `@media (max-width: 600px)` перестраивает шапку и подвал в столбик. Карточки перестраиваются автоматически благодаря Grid. Горизонтальная прокрутка отсутствует на всех ширинах.

## Как открыть

1. Скачать или клонировать репозиторий.
2. Открыть файл `index.html` в браузере.

Никаких сборок и установок не требуется — это статическая страница на чистом HTML и CSS.
